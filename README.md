## วิธีรันระบบด้วย Docker (สำหรับผู้ร่วมพัฒนา)

### สิ่งที่ต้องเตรียม
1. ติดตั้งโปรแกรม Docker Desktop และเปิดใช้งานให้เรียบร้อย

### ขั้นตอนการรัน
1. สร้างไฟล์ `.env` โดยคัดลอกรูปแบบจากไฟล์ตัวอย่าง:
   ```bash
   cp .env.example .env
2. รันคำสั่งนี้ใน Terminal
    docker compose up --build
3. เข้าใช้งาน:

Frontend: เข้าผ่านเบราว์เซอร์ที่ http://localhost

Backend API: พอร์ต http://localhost:8080
4. เมื่ออยากปิดระบบ ใช้คำสั่งนี้ใน Terminal
docker compose down
